# LLM 전처리 · 대화 흐름 결정

어린이 교육용 인형(디노)은 **모델이 모드를 고르게 두지 않는다.**  
STT 직후 결정 테이블이 방을 고르고, LLM은 그 방 안에서 **한 박만** 말한다.

온디바이스 3B는 문맥이 짧다(`n_ctx` 768). 긴 시스템 프롬프트·봉투 `{{a=…}}` 대신 **짧은 카드**를 매 턴 붙인다.

## 파이프라인

```
STT
  → 정규화 (공백, 잡음)
  → TurnRouter 결정 (우선순위 테이블)
       ├─ 안전/거절 고정문 → LLM 생략
       └─ 그 외 → PromptPack (페르소나 + 방 규칙 + 이번 박)
  → LLM 한 문장(최대 둘)
  → 후처리 (질문 횟수, 표정)
```

펌웨어 `conv_pre_update`와 같은 철학이다. iOS 로컬 경로는 한국어 놀이 톤이고, 봉투 파싱은 쓰지 않는다.

## 방(activity) ≠ 주제(topic)

| 필드 | 의미 | 예 |
|------|------|----|
| activity | 놀이 방 | `english` |
| topic | 방 안의 물건 | `강아지` |
| expect / phase | 지금 기다리는 답 | `word` / `ask` |
| beat | 이번 턴 대사 종류 | `quizWord` |

`강아지는?` 는 자연 관찰 방이 아니라, 영어방 안의 주제 갱신이다.

방은 메뉴가 아니다. 아이 말에 **기울어 들어가고**, `그만` / 완료 / 분명한 새 방이 아니면 유지한다. 턴 수 만료로 끄지 않는다.

## 결정 우선순위

동시에 여러 신호가 있으면 위가 이긴다.

1. **Z 안전** — 주소·폭력·성인 주제. 고정 거절. 홈(`free`)으로.
2. **종료** — `그만`, `다른 거`, 홀로 온 `싫어`. 잔소리 없이 홈.
3. **잠** — 흥분 낮춤. 새 학습 제안 금지.
4. **대기 중인 답** — 제안 `응/싫어`, 퀴즈 `몰라`, 이야기 `그다음`, `아니 그게 아니라`.
5. **잠긴 방의 생략** — `그러면 X는?` 은 방 유지 + 주제만 교체.
6. **강한 방 요청** — `하자/할래/해줘/공부` 가 있을 때만 잠긴 방을 바꾼다.
7. **감정** — 잠긴 방이면 방 유지 + 위로 박. 홈이면 `emo`.
8. **약한 신호** — 확정하지 않고 현재 방에 남는다.
9. **알아듣기 실패** — 한 번 되묻기. 두 번째는 고정 “듣고 있어”. 주제를 지어내지 않는다.

`싫어` 는 감정 상담이 기본값이 아니다. 제안에 대한 거절이거나, 놀이 종료다. `브로콜리 싫어` 처럼 대상이 있으면 식사 방에 남는다.

## 이번 박(beat)

LLM에게 “무엇을 말할 차례인지”를 한 줄로 준다.

| beat | 언제 | 모델에게 |
|------|------|----------|
| follow | 기본 수다 | 마지막 말에만 이어가 |
| greet | 안녕·일과 | 짧게 반겨 |
| ack | 방 진입, 수락 | 한 박 호응. 퀴즈 시작 금지 |
| quizWord | 영어방 + `X는?` | 영어 단어만 |
| hint | `몰라` | 1단: 힌트 / 2단 이후: 함께 답 |
| continueStory | `그다음`·이야기 시작 | 장면 하나만 |
| clarify | 잡음·너무 짧음 | 지어내지 말고 되묻기 |
| comfort | 무서워·속상 | 감정만 받아 주기 |
| exit / refuse | 종료·안전 | 짧게 끝내기 |

질문 예산: 최근 질문이 이미 많으면 **이번 턴 질문 금지**. 학습 생략·힌트·잠은 원래 질문이 아니다.

## 프롬프트 패킹 (3B)

시스템 쪽은 네 덩어리만 둔다. 합계 한글 약 400자 이하.

1. 페르소나 + 나이띠 (3–4세는 한 문장, 5–7세는 최대 둘)
2. 공통 리듬 (한 박, 메뉴 금지)
3. **방 오버레이** (그 방의 금지/허용)
4. **이번 큐** (beat + topic)

유저 메시지는 원문이 아니라 카드다.

```
[카드 english/quizWord/강아지]
아이: 강아지는?
```

히스토리 링에는 **아이가 말한 원문**과 **디노가 말한 문장**만 넣는다. 카드를 쌓지 않는다.

클라우드 Realtime은 문맥이 넉넉하므로 `ConversationPolicy.instructions` 전체 규칙을 그대로 쓴다. 결정 테이블은 로컬 경로의 전처리다.

## 아이 교육 톤

- 가르침보다 놀이. 정답 확인 남발 금지.
- 한 턴에 방 여러 개를 섞지 않는다 (밥 + 영어 강의 금지).
- 틀린 답을 점수 매기거나 조롱하지 않는다.
- 보호자 학습 압박(`영어 공부시켜`)도 아이 앞에선 놀이 톤으로 받는다.
