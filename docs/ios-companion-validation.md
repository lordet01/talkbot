# Swift 디노 앱 — 실기기 검증

## 검증 범위

자동 테스트는 대화 UI 상태, 취소된 응답 차단, Realtime 이벤트 형식, 지연 통계, 시선 필터를 확인한다. iOS 시뮬레이터 빌드는 Apple SDK 컴파일을 확인한다. 이 둘은 실제 어린이의 음성 인식, AEC, 스피커 첫 소리, 아이트래킹 정확도, LLM 대화 품질 검증을 대신하지 않는다.

2026-10-04 작업 검증: Swift 코어 XCTest **15/15 통과**, 기존 Python 대화 상태 테스트 **16/16 통과**, iOS Swift 소스 파싱 통과. 현재 Linux 작업 환경에는 Apple SDK가 없어 iOS 빌드는 실행하지 못했다. GitHub 쓰기 연결이 `403 Resource not accessible by integration`으로 막혀 CI도 실행하지 못했다. Xcode 빌드·실기기 음성·시선·API 테스트는 미검증이다.

## 지연 기준

측정 구간은 **아이가 말을 끝낸 시각 → 디노의 의미 있는 첫 답변 음성이 들리는 시각**이다. 준비/연결 시간은 별도다. 맞장구나 애니메이션은 답변으로 계산하지 않는다.

실제 배포 후보 iPhone / iPad를 가로 스탠드에 놓고 30–100cm 거리에서 보호자가 우선 테스트한다. 외부 녹음 또는 고속 영상으로 아이의 마지막 발성과 스피커 첫 답변 음성을 확인한다. 보호자 화면의 추정치와 대조한다. Wi-Fi, 셀룰러, 약한 연결을 따로 기록한다. API 모델, 기종, OS, 거리, VAD 설정을 같이 남긴다.

- 정상 연결에서 100턴 이상 측정하고 median / P95 / P99 / 최대값과 1초 초과 횟수를 보고한다.
- 1초 이내의 **보장**을 주장하려면 정의된 조건에서 예외 없는 근거와 초과 시의 운영 정책이 필요하다. 현재 구현에는 이 보장이 없다.
- 느린 응답과 실패를 제외해서 성공률을 높이지 않는다. 무음/인식 실패, 8초 타임아웃, 끼어들기는 별도 수치를 함께 보고한다.
- 응답 첫 음성 지연, 문장 완성 지연, 말 끊김 비율을 구분한다.

## 대화 회귀 시나리오

| 아이 입력 / 순서 | 기대하는 동작 |
|---|---|
| 영어놀이 하자 → 강아지는? → 고양이는? | 영어놀이를 유지하고 해당 단어에 답하기 |
| 몰라 → 그래도 몰라 | 작은 힌트 → 함께 답하기, 같은 질문 반복 금지 |
| 사과는? → 아니 과일 말고 배 타는 배 | 수정된 뜻을 반영, 새 활동으로 이동 금지 |
| 토끼 동화 들려줘 → 그다음 → 계속 | 토끼 이름과 사건을 유지, 한 장면씩 |
| 싫어 / 그만 / 안 할래 | 즉시 활동 중단, 설득·감정 상담으로 새지 않기 |
| 응 / 아니 / 네 | 짧은 답을 인식하고 이전 질문 맥락 유지 |
| 300–700ms 생각 쉼 후 문장 이어 말하기 | 자주 잘리면 보호자가 기다리기 옵션으로 조절 |
| 무서워 / 속상해 | 공감, 필요하면 가까운 보호자 도움 안내 |
| 불명확한 소리 / 무음 | 내용 지어내지 않기, 반복 질문·자동 말을 강요하지 않기 |
| 디노 답변 중 아이가 말 시작 | 스피커 정지, 아이 말 듣기, 이전 답의 뒷부분이 다시 나오지 않기 |

10–20턴 자유 대화도 확인한다. 프롬프트의 문장 수·질문 빈도는 생성 모델 지침이므로 실제 결과에서 별도 점검한다. 보호자 동의·감독 하의 어린이 테스트는 보호자 테스트 이후 수행한다.

## 오디오·상태 회귀

- 큰 스피커 볼륨에서도 자기 목소리를 아이의 새 발화로 오인하지 않는지.
- 끼어들고 다시 끼어들기, 응답 완료 직전 끼어들기, 응답 직후 새 질문.
- LTE/Wi-Fi 전환, 연결 끊김, 잘못된 키, 사용 불가 모델, API 제한, 8초 첫 음성 타임아웃.
- 빠르게 시작/중단/재시작했을 때 이전 세션의 자막·음성이 나오지 않는지.
- 앱 백그라운드, 화면 잠금, 전화, 이어폰 연결/해제 시 마이크·카메라가 멈추는지.
- 종료 후 녹음·카메라 표시가 꺼지고 자동으로 다시 켜지지 않는지.
- 암호/Face ID 인증 취소 시 설정에 접근하지 못하는지. API 키가 로그·UserDefaults에 남지 않는지.

## 카메라·표정 회귀

- landscapeLeft / landscapeRight 모두에서 좌우·상하 이동 방향 확인. 전면 카메라 미러링은 실기기에서 확인.
- 기기를 보는 경우와 옆을 보는 경우를 비교. 안경·조명·거리별 오차를 관찰.
- 얼굴을 가리거나 화면 밖으로 나가면 700ms 후 눈동자가 중앙으로 돌아오는지.
- ARKit 미지원 기기 / AR 세션 실패 / 카메라 권한 거절에서도 음성 대화 가능한지.
- 여러 얼굴에서 추적 대상이 급격하게 튀지 않는지. ARKit은 한 얼굴, Vision은 가장 큰 얼굴을 선택한다.
- 보호자 설정 진입 중 Face ID와 ARKit 카메라가 충돌하지 않는지.
- VoiceOver와 동작 줄이기 설정에서 시작·중단·보호자 설정을 사용할 수 있는지.

현재는 정밀 시선 보정·어린이 실험·실시간 API 실측 결과가 포함되어 있지 않다. 실제 출시 전 이 문서에 결과를 추가한다.
